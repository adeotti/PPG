* **Bias :** The environment version on which all these policies were trained and tested does not let them corrupt the board, meaning a policy cannot modify a correct cell it has previously filled. This is one of, if not the main reason these trained policies are able to "generalize" so well. A more or less unbiased and closer-to-the-truth version would let the policies corrupt the board if they try to modify a previously filled correct cell with a new bad value. This should make learning much harder, and generalization in this version of the environment will be closer to the truth.

* **KL Divergence Explosion during the Auxiliary Phase :** I initially computed the kl using the probabilities coming from the post-masked logits. Since invalid actions are masked by setting their logits to -inf before the softmax, their resulting probabilities become zero.This causes a numerical issue in the KL divergence : KL contains terms like log(p) and log(q), and log(0) → -∞, which makes the KL blow up to `inf`.An easy fix was to use the raw (unmasked) logits to compute the KL divergence.

* **Experiments :** The model`sumo_v0_4k` was trained on a single board and on only ~4 million transitions but is remarkably, and for reasons I can't explain, able to generalize on boards it has never seen during training while always beating the baseline for that environment it was trained on, which is a random policy's total steps for n episodes. This implies that resetting the environment with different boards is not necessary and that a policy is able to learn a general strategy to solve these boards even when all the training data are coming from a single source.
The model `sumo_v0_10k`, on the other hand, was also trained on a single board and displays the same capabilities as the first model trained on 4 million transitions, which implies that more training time is perhaps not necessary and that 4 million transitions or even less can be enough for a policy to display some signs of learning.
